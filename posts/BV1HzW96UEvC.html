DeepSeek Harness 的 64 天：25,848 个提交与 100% 覆盖率

UP：catface996 · BV1HzW96UEvC · 2026-11-14

一句话总结用 git 记录还原：06-10 首提交、08-13 公开，内部 64 天 25,848 个提交；第二天立下逐文件 100% 覆盖率并补 59 个测试；TUI 18 天加入又删除，42 个版本全是 RC/alpha，暂不收外部 PR。

一句话总结

这期用 git 记录还原 DeepSeek Harness 的“64 天”：2026-06-10 第一个提交，08-13 仓库公开；内部 64 天写了 25,848 个提交，公开时已有完整测试与 100% 逐文件覆盖率，但截至 11-11 的 42 个版本全是 RC/alpha，没有正式版。

视频讲了什么

开场先纠正一个直觉：GitHub 仓库创建日期写 08-13，但第一个提交是 06-10，所以“刚开源就这么完整”其实是内部已经做了 64 天。第一版 README 只有几行，标题是 DeepSeek Harness，说明这是该组的 monorepo，项目清单只有一项——DeepSeek Code，也就是编程 Agent 产品。

第二天 06-11 的提交立下规矩：packages 下各包源码要逐文件、逐行、逐分支都有测试，覆盖率 100%；同一个提交补了 59 个测试。07-04 的提交改写 README，删掉 DeepSeek Code 那一条，改成“DeepSeek Harness SDK 是一个基于插件、用来搭建 Agent Harness 的 SDK”。

接着把模型公告与仓库记录拆成两条轨：07-31 V4-Flash 正式版公告提到用 DSH 极简模式做 code agent 评测；08-13 V4-Pro 公告没提 DSH，只和仓库公开同一天；08-21 视觉实验版又提到 DSH；10-17 V4.1-Flash 公告说针对 DSH 等框架优化，请升级到 0.2.1-RC1 以上。作者强调：同一天只算日期重合，不当因果。

增长部分：6 月 579 个提交、7 月 8,088、8/9 月各 6,000+、10 月 4,000+，合计 25,848，平均每天约 175 个（含合并提交）。7 月加进 TUI 包，18 天后 08-04 又连入口一起删掉，一次改动 430 个文件、删 28,905 行。会话文件格式半个月从 V1 升到 V4。

公开仓库目前 27 万多星，issues 开着、discussions 关着，贡献指南写明暂不接受外部 PR。作者给读法：看提交、看设计笔记、看官方公告，按来源挂角标；并提醒 100% 覆盖率的代价是测试代码量——tests 目录约 72.5 万行，比 src 的 53.4 万行还多（含空白、注释、测试数据）。

关键点

  • 64 天：06-10 首提交到 08-13 公开，不是“公开后才开始做”。
  • 25,848 个提交：平均每天约 175 个，7 月最多 8,088。
  • 100% 逐文件覆盖率：第二天立规，同提交补 59 个测试。
  • TUI 18 天生死：07-17 加入，08-04 删除，删 28,905 行。
  • 42 个版本无正式版：全部带 RC/alpha 后缀。
  • 模型公告三次点名：两次当评测框架，一次请升级；08-13 只日期重合。
  • 读法：提交/笔记/公告分来源，别把同一天当因果。
