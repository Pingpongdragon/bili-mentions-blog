DeepSeek V4.1-Flash：890 字节/token 的 KV 缓存是怎么做到的

UP：为什么叫QQ · BV1uMYj6mEGA · 2026-11-22

一句话总结552B MoE，每 token 全局 KV 890 字节；CED 20+20 层让 prefill 只跑前 20 层、激活约 8B，CSA2 分层稀疏+FP4+SWA 有界回放把 HBM 压到 1/4、SSD 1/8；后训练算法不变，收益来自数据管线与百万级沙箱。

一句话总结

这期拆 DeepSeek V4.1-Flash：552B MoE，每 token 全局 KV 缓存压到 890 字节，靠 CED 因果编码器、CSA2 稀疏注意力、FP4 与 SWA 有界回放，把 HBM 占用压到约 1/4、SSD 压到约 1/8；后训练没换算法，收益主要来自数据管线与百万级沙箱。

视频讲了什么

开场先给矛盾：名字是“跑量小模型”，跑分却反超自家 V4-Pro；552B 参数，每 token 全局 KV 只有 890 字节，上一代 V4-Flash 是 3514 字节，2023 年的 V1 是 38 万字节，三年压了 437 倍。作者提醒：Agent 长任务里模型大部分时间在读代码、读工具返回、读几十轮历史，缓存命中率常年 98% 以上，账单大头是输入与缓存，不是生成。

第一层改动是 CED 因果编码器：40 层 Transformer 劈成前 20 层编码器、后 20 层解码器；解码器的全局 KV 不从本层隐状态算，直接拿第 20 层输出乘每层投影矩阵。效果是 prefill 只跑前 20 层，后 20 层的全局 KV 相当于“白减”，处理新提示词时激活参数只要 8B。思路来自微软 YOCO 论文，DeepSeek 补了逐层滑窗、百万 token 训练，做成生产模型。

第二层是 CSA2 压缩稀疏注意力：每层静态分配 full / random / reuse 三种模式，编码器层算全局 KV 和索引，后面大量 reuse 层直接复用缓存与 top-k 索引，只算 query 和局部滑窗。首个 full 层扫描全上下文，挑出 2048 个块、每块 8 个位置，共 16,384 个候选，后续索引器只在这个池子里选最多 512 条；上下文涨到 100 万，后续每层索引开销也不变。

890 字节是三条压缩叠加：共享 latent + FP4 量化、多个 token 压成一条缓存、跨层复用。主 KV 用 1-bit 加每 16 通道一个缩放因子，索引器 K 用 MXFP4，局部滑窗保持 FP8；四个缓存 bank 三个 2:1、一个 1:1，算下来每原始 token 正好 890 字节。显存活缓存小 4 倍，SSD 持久缓存只剩 1/8——滑窗注意力的 KV 干脆不持久化，缺 SWA 时用 Bounded Replay 回放最近 128 个 token 重建近似局部状态，官方承认这是近似、不是等价。

训练部分：45T token 多模态语料预训练后，没有新算法，SFT + RL + OPD 蒸馏都是标准配方；收益来自数据管线——大规模自动合成任务，每个任务配“问题/环境/验证”，用难度和正确性做奖励，让模型自己造题、自己验题；RL 后的轨迹再回流做任务质量再审。支撑它的是 DSec 弹性沙箱，同时跑几百万实例，单机 2500 个活容器，用最终一致性换规模；安全上每个沙箱配 AppArmor + eBPF 网络策略，因为 RL Agent 会奖励作弊。

还有两个工程点：可控推理强度，在系统提示词里写 1–100 的 effort，奖励里的长度惩罚随 effort 指数衰减，API 暴露 low=50 / high=75 / max=100，简单任务开低档省输出 token；DeepJIT 是 header-only C++20 库，给 CUDA 与昇腾 NPU 做运行时 kernel 编译、缓存、加载，缓存键包含源码、include、编译器版本、编译选项，多节点共享缓存。

跑分：Terminal Bench 2.1 90.6、DeepSWE v1.1 74.2（V4-Pro 62.7）、Codeforces 3471、SWE-bench 88.1；弱项 GPQA 90.9 低于 Kimi K3 的 92.9，HLE 36.8 离 Opus 5.5 的 56.3 差距明显。作者建议把 Agent 成本拆三笔账：计算（输入重用 CED 类不对称架构）、存储（缓存命中与未命中差 50 倍，prompt 前缀稳定、系统提示放前、变量放后）、带宽（长会话注意缓存保活，DSK 全局 KV 至少 72 小时）。

关键点

  • 890 字节/token：比 V4-Flash 的 3514 字节小约 4 倍，比 V1 小 437 倍。
  • CED：20 层编码器 + 20 层解码器，prefill 只跑前 20 层，激活约 8B。
  • CSA2：full/random/reuse 分层，候选池 16,384 选 512，长上下文索引开销不涨。
  • 压缩三叠加：共享 latent + FP4、token 合并、跨层复用；HBM 1/4、SSD 1/8。
  • Bounded Replay：SWA 不持久化，缺缓存回放 128 token，近似而非等价。
  • 后训练：算法不变，收益来自数据管线、自动合成任务与百万级沙箱。
  • effort 旋钮：1–100 可控推理强度，API 三档，省输出 token。
